# Test Project

This is a simple test project to demonstrate how to create and manage a code repository on Gitee.

## File Structure

- `.gitignore` - Specifies files and directories to be ignored by Git.
- `1.txt` - A simple text file.
- `poem.txt` - A text file containing poetry content.

## Usage Instructions

1. Clone the repository to your local machine:
   ```bash
   git clone https://gitee.com/cyj154554/test.git
   ```

2. View the contents of the `.gitignore` file:
   ```bash
   cat .gitignore
   ```

3. View the contents of the `1.txt` file:
   ```bash
   cat 1.txt
   ```

4. View the contents of the `poem.txt` file:
   ```bash
   cat poem.txt
   ```
