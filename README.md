# 测试项目

这是一个简单的测试项目，用于演示如何在 Gitee 上创建和管理代码仓库。

## 文件结构

- `.gitignore` - 用于指定 Git 忽略的文件和目录。
- `1.txt` - 一个简单的文本文件。
- `poem.txt` - 一个包含诗歌内容的文本文件。

## 使用说明

1. 克隆仓库到本地：
   ```bash
   git clone https://gitee.com/cyj154554/test.git
   ```

2. 查看 `.gitignore` 文件内容：
   ```bash
   cat .gitignore
   ```

3. 查看 `1.txt` 文件内容：
   ```bash
   cat 1.txt
   ```

4. 查看 `poem.txt` 文件内容：
   ```bash
   cat poem.txt
   ```
